# Книги_vesr-gns3
Руководство по работе с виртуальным маршрутизатором vESR  в GNS3 в двух книгах. Для начинающих и тех, кто одолел первую книгу

Современные сетевые технологии требуют не только теоретических знаний, но и практических навыков работы с оборудованием. Однако доступ к реальным маршрутизаторам и коммутаторам зачастую ограничен, особенно на этапе обучения. Выходом становится использование виртуальных сред, таких как GNS3, которые позволяют моделировать сложные сети на обычном компьютере.

Первая книга для новичков в сетевых технологиях и посвящена работе с виртуальным сервисным маршрутизатором vESR от Eltex. vESR. Вторая более глуюоко погружает в возможности использования этого маршрутизатора в разных сценариях.
